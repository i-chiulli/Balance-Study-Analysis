# Balance-Study-Analysis

PROJECT TITLE/DESCRIPTION:
ISway Study Replication - Analysis
Imports data from replication study in which participants completed 4 tasks with varying levels of difficulty to assess balance. The script calibrates the 3-axis accelerometer data to the world frame for each task, then creates plots of calibrated and uncalibrated acceleration data. Computes balance metrics used in ISway study and visualizes metrics using box plots. Calculates means and standard deviations of these metrics for each task. Looks for statistically significant differences of metrics between tasks.

INSTALLATION & APPLICATION:
Ensure script, module, and data are in your directory.
Script: wearables unit 1
Module: balance_metrics
